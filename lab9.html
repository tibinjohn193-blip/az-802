Account lockout threshold PropertiesX
Account will lock out after: invalid logon attempts
Explain:
This security setting determines the number of failed logon attempts that causes a user account to be locked out. A locked-out account cannot be used until it is reset by an administrator or until the lockout duration expires.

Lab Requirement: Set this value to 3 invalid logon attempts.
Suggested Value ChangesX
