# 🛡️ Lab 4: Active Directory User Management

## 📌 Project Overview
This project is a browser-based, fully interactive web application designed to help students and IT professionals practice essential Active Directory management tasks. It provides a risk-free, hands-on environment that perfectly mirrors Windows Server 2025.

## 🎯 What's Inside This Lab? (Tasks Covered)
In this hands-on lab, you will perform the following real-world system administration tasks step-by-step:
    
1. **Open ADUC:** Use the `dsa.msc` Run command to launch the Active Directory console.
2. **Create an Organizational Unit (OU):** Build a new administrative container named `IT_Dept`.
3. **Create a New User:** Set up a user account (`Tibin John`) with specific password policies (e.g., Password never expires).
4. **Reset Password:** Perform an administrative password reset for the user.
5. **Disable / Enable Account:** Temporarily restrict and restore user access using context menus.
6. **Set Account Expiration:** Configure a specific end date for the user account to automatically expire.
7. **Workstation Logon Restrictions:** Apply security policies to restrict the user to log on only from a specific computer (`PC-01`).
8. **Manage Security Groups:** 
   - Create a new security group (`IT_Admins`).
   - Add the user to the newly created group.
   - Verify group membership and successfully remove the user from the group.

## 🚀 Key Features
- **100% Authentic UI:** Replicates the exact look, feel, icons, and context menus of Windows Server 2025.
- **Interactive Lab Guide:** A dynamic, floating instruction panel that perfectly syncs with your actions and prevents skipping steps.
- **Smart Validation:** Handles inputs intelligently (e.g., case-insensitivity for PC names) and provides helpful alerts for incorrect entries.
- **Zero Dependencies:** Runs entirely in your web browser using HTML, CSS, and Vanilla JavaScript. No backend or internet required.

## 🛠️ How to Run
1. Download or save the source code as an HTML file (e.g., `lab4.html`).
2. Double-click the file to open it in any modern web browser (Chrome, Edge, Firefox).
3. Follow the sequential instructions displayed in the **Lab Guide** panel.
