
# ☁️ Microsoft AZ-802: Windows Server & Azure Hybrid Administration

Welcome to the interactive study repository for **Microsoft AZ-802**. This repository contains hands-on lab simulations, setup guides, and study materials designed to help you master Windows Server and Microsoft Azure hybrid environments.

## 🚀 Overview
This project provides **100% browser-based interactive simulations** for complex server administration and cloud deployment tasks. Practice setting up Active Directory, managing hybrid identities, configuring network settings, and securing infrastructure without needing a heavy Virtual Machine or Azure subscription.

## ✨ Key Features
- **Interactive Browser Labs**: Practice Server 2025 and Azure configurations directly in your web browser.
- **Zero Setup Required**: No ISOs, VMs, or Azure cloud credits required to practice the UI steps.
- **Highly Realistic UI**: Authentic Windows Server Manager, MMC snap-ins (`dsa.msc`, `diskmgmt.msc`), and Azure Portal interfaces.
- **Skill Validation**: Built-in exam simulators that test your knowledge without step-by-step guidance.
