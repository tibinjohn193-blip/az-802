Static vs. Default Routing:
• Static Route: Routes a specific network (e.g. 192.168.2.0 / 255.255.255.0) via Gateway 192.168.1.1.
• Default Route: Uses 0.0.0.0 / 0.0.0.0 → Gateway 192.168.1.1 so any IP whose gateway points to the server reaches it automatically!
